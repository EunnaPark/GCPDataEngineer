# GCP Data Engineer Study

Hands-on labs and study notes for the Google Cloud Professional Data Engineer certification. Each folder holds one lab: a README with the procedure and notes, plus reusable SQL or shell scripts where available.

## Labs by topic

### Ingestion and pipelines

| Lab | What it covers |
|---|---|
| [Cloud Run Functions to Load BigQuery](Cloud%20Run%20Functions%20to%20Load%20BigQuery/) | Event-driven loads from Cloud Storage into BigQuery |
| [Streaming Data Pipeline with Dataflow](Streaming%20Data%20Pipeline%20for%20a%20Real-Time%20Dashboard%20with%20Dataflow/) | Pub/Sub → Dataflow → BigQuery streaming and a real-time dashboard |
| [Serverless for Apache Spark](Serverless%20for%20Apache%20Spark/) | Running Spark batch jobs without a cluster to load BigQuery |
| [Datastream: PostgreSQL to BigQuery](datastream-postgresql-replication-to-bigquery/) | CDC replication from Cloud SQL for PostgreSQL |
| [Dataform](Dataform/) | SQL workflows and dependency management in BigQuery |

### Storage and analysis

| Lab | What it covers |
|---|---|
| [Cloud Storage data lake through BigQuery](Cloud%20Storage%20data%20lake%20through%20BigQuery/) | Connections, Lakehouse tables, and access policies |
| [SQL in BigQuery](SQL%20in%20Bigquery/) | Console, CLI, ecommerce and COVID challenges, troubleshooting |
| [BigQuery ML](BigQuery%20ML/) | Classification model to predict visitor purchases |

### Visualization

| Lab | What it covers |
|---|---|
| [Looker](Looker/) | Explores, measures, merged results, and dashboards |
