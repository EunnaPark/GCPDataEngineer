# Looker Lab Reuse Checklist

## Before running

- Confirm the current lab Looker instance and temporary credentials.
- Open FAA → Airports and inspect available fields.
- Inspect the modeled Average elevation and Count definitions, source grain, and units.
- Record active filters and access limitations.

## Single-value tile

- Select only Average elevation for the overall result.
- Run and record the number without claiming unverified units.
- Select Single value; set a meaningful title.
- Save Average elevation to Airports/Flights.

## Facility-type comparison

- Select Facility type, Average elevation, and Count.
- Sort Average elevation descending, then set row limit five.
- Run; confirm grouping and order in the results table.
- Choose the horizontal bar chart and enable value labels.
- Match each axis name to its assigned measure; verify units and scaling.
- Save Average elevation by facility type to the same dashboard.

## After running

- Open the dashboard and confirm both tiles exist.
- Record numerical results and the lab progress outcome.
- Save a screenshot/export without credentials or account details.
- Report unexpected behavior separately from course-provided steps.
